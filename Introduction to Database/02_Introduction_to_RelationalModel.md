# Database Systems - Lecture 02: Introduction to Relational Model

## 📌 1. 기본 개념 (Basic Concepts)
데이터베이스에서 **관계형 모델(Relational Model)**은 데이터를 2차원 테이블 형태로 표현하는 방식입니다.

* **Relation (릴레이션)**: 데이터베이스의 테이블(Table)을 의미.
* **Tuple (튜플)**: 릴레이션의 각 행(Row) 또는 레코드(Record)를 의미.
* **Attribute (속성)**: 릴레이션의 각 열(Column)을 의미.
* **Domain (도메인)**: 특정 속성이 가질 수 있는 허용된(원자적인) 값들의 집합. (Null 값은 '알 수 없거나' '존재하지 않음'을 의미함)

### 💡 Relation Schema vs. Relation Instance
* **Relation Schema ($R$)**: 릴레이션의 구조적 정의 (예: `instructor = (ID, name, dept_name, salary)`)
* **Relation Instance ($r(R)$)**: 특정 시점에 릴레이션에 실제로 저장되어 있는 데이터들의 집합.

---

## 🔑 2. 키 (Keys)
튜플을 유일하게 식별하거나 릴레이션 간의 관계를 맺기 위해 사용되는 개념입니다.



* **Superkey (수퍼키)**: 릴레이션 내의 튜플들을 유일하게 식별할 수 있는 하나 이상의 속성 집합.
* **Candidate Key (후보키)**: 수퍼키 중에서 **최소성**을 만족하는 키.
* **Primary Key (기본키, PK)**: 후보키 중에서 명시적으로 선택한 주 식별자. (밑줄 `_`로 표시)
* **Foreign Key (외래키, FK)**: 한 릴레이션의 속성이 다른 릴레이션의 기본키를 참조하는 식별자.
  * **참조 무결성 제약조건 (Referential Integrity Constraint)**: 외래키의 값은 반드시 참조되는 릴레이션의 기본키에 존재하는 값이어야 함.

## 🧮 3. 관계대수 (Relational Algebra) - 기본 및 추가 연산자
관계대수는 원하는 정보를 얻기 위해 데이터를 어떻게(How) 연산해야 하는지 기술하는 절차적 언어입니다.

1. **Select (선택, $\sigma$)**: 주어진 조건식을 만족하는 **튜플(행)** 추출. (조건식 안에 $\lor$(OR), $\land$(AND), $\neq$(다름) 등 사용 가능)
2. **Project (추출, $\Pi$)**: 릴레이션에서 특정 **속성(열)**들만 추출 (중복 자동 제거).
3. **Union (합집합, $\cup$)**: 두 릴레이션의 결과를 합침 (OR의 역할).
4. **Set Difference (차집합, $-$)**: 첫 번째 릴레이션에는 있지만 두 번째에는 없는 튜플을 찾음 (다름/제외의 역할).
5. **Cartesian Product (카티션 곱, $\times$)**: 두 릴레이션 튜플들의 **모든 가능한 조합** 생성.
6. **Rename (이름 변경, $\rho$)**: 릴레이션이나 속성에 새로운 이름 부여.
7. **Set Intersection (교집합, $\cap$)**: 두 릴레이션에 공통으로 있는 튜플을 찾음.
8. **Natural Join (자연 조인, $\bowtie$)**: 두 릴레이션에서 공통 속성(예: `ID`)의 값이 일치하는 튜플들만 결합. (카티션 곱 + Select + Project의 결합 형태)

---

## ➗ 4. Division (나눗셈, $\div$) 연산자



나눗셈 연산은 주어진 타겟 릴레이션의 **'모든'** 조건을 만족하는 데이터를 찾을 때 사용합니다. 카티션 곱($\times$)의 정확히 반대되는 작업을 수행합니다.

* **예시**: 타겟 프로젝트 테이블 $S$가 `{p2, p4}` 라면, 전체 테이블 $R$에서 **`p2`와 `p4`를 모두 수행하는** 사람의 ID만 찾아냅니다.
* **특징**: 나눗셈은 5가지 기본 연산자로 길게 풀어쓸 수 있는 파생 연산자입니다.
* 🚨 **Prof's Tip (시험 꿀팁)**: 수업 대본에 따르면, 교수님께서 "이 긴 수학 공식은 나도 싫어하니 **중간고사에서 완전히 무시(ignore)해도 된다**"고 강조하셨습니다. (원리만 알면 됨!)

## 📊 5. Group By (그룹화) 및 집계 연산자 ($\gamma$ 또는 $G$)



데이터를 특정 속성을 기준으로 묶은 뒤, 평균(AVG), 최대(MAX), 최소(MIN), 개수(COUNT) 등의 집계를 계산합니다.

* **표기법**: `[분류 속성] G [집계 함수] (테이블명)`
  * **분류 속성 (좌측)**: 그룹을 나눌 기준 (예: `dept_name` 학과별). 이를 기준으로 데이터를 정렬(Sort)하여 묶습니다.
  * **집계 함수 (우측)**: 묶인 그룹에 적용할 통계 함수.
* 🚨 **Prof's Tip (슬라이드 오류 정정)**: 슬라이드 예제 중 `dept_name G avg(salary) (instructor)`의 결과에서 Physics 학과의 값이 95,000으로 적혀 있습니다. 교수님께서 대본을 통해 **"이건 값을 그대로 복붙해서 생긴 오류이고, 집계 함수가 `max(salary)` 였다면 95,000이 맞지만, `avg`라면 진짜 평균을 새로 계산해야 한다"**고 직접 정정하셨습니다.
* **그룹 속성이 없는 경우**: 좌측의 분류 기준을 아예 비워두면(예: `G count(ID) (instructor)`), 테이블 전체 레코드를 하나의 큰 그룹으로 취급하여 총 개수 등 스칼라 값 하나만 반환합니다.

## 📝 6. 중간고사 대비 연습 문제 (Practice Questions)
교수님께서 수업 마지막에 **"자연어 쿼리를 관계대수식으로 바꾸는 문제가 중간고사에 출제된다"**며 강조하신 핵심 연습 문제들입니다.

1. 컴퓨터공학과(Comp. Sci.) 소속 모든 강사의 이름을 찾으시오.
2. 컴퓨터공학과에서 제공하는 모든 과목의 제목(title)을 나열하시오.
3. 총 학점(tot_cred)이 100학점이 넘는 학생들의 이름을 찾으시오.
4. 2023년 가을학기(Fall 2023) **또는** 2024년 봄학기(Spring 2024)에 과목을 수강한 학생의 ID를 찾으시오. (Union $\cup$ 활용)
5. 2023년 가을학기에는 수강했지만, 2024년 봄학기에는 수강하지 **않은** 학생의 ID를 찾으시오. (Set Difference $-$ 활용)
6. "Einstein" 강사가 가르치는 과목을 수강한 학생들의 이름을 찾으시오.
7. 컴퓨터공학과에서 개설한 **모든(every)** 과목을 수강한 학생의 ID를 찾으시오. (Division $\div$ 활용)
8. 과목을 한 번도 수강하지 않은 학생의 이름을 찾으시오.
